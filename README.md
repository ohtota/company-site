# ボーズ株式会社 コーポレートサイト

架空のソフトウェア会社「ボーズ株式会社」のコーポレートサイトのサンプルです。HTML・CSS・JavaScript を `index.html` 1ファイルにまとめており、ビルドや依存パッケージのインストールは不要です。

## サイトの構成

1ページ構成で、上から次の順に並んでいます。

| セクション | 内容 |
| --- | --- |
| ナビゲーション | 各セクションへのリンク。画面上部に固定表示 |
| お知らせ | 最新のお知らせ（日付・カテゴリ・タイトル） |
| ヒーロー | キャッチコピーと、粒子が集まるアニメーション（canvas） |
| 事業内容 | 受託開発・自社SaaS・技術顧問 |
| プロダクト | ヒッグス・フォトン・グラビトン |
| 開発の進め方 | 観察 → 試作 → 開発 → 運用 |
| 会社概要 | 沿革と会社情報 |
| 採用情報 | 募集職種の一覧 |
| お問い合わせ | 連絡先と問い合わせフォーム |

- ライト／ダークテーマは OS の設定に合わせて切り替わります。
- スマートフォン幅にも対応しています。
- 問い合わせフォームは入力内容の確認だけを行い、実際には送信しません。

## index.html を開く手順

### ブラウザで直接開く

1. エクスプローラー（Windows）や Finder（macOS）で `index.html` があるフォルダを開きます。
2. `index.html` をダブルクリックするか、ブラウザのウィンドウにドラッグ＆ドロップします。

フォントは Google Fonts から読み込むため、インターネットに接続していない場合は代替フォントで表示されます。

### ローカルサーバーで開く

ファイルを直接開く代わりに、ローカルサーバー経由で表示することもできます。`index.html` があるディレクトリで次のどちらかを実行します。

```bash
# Python を使う場合
python3 -m http.server 8000

# Node.js を使う場合
npx serve -l 8000
```

ブラウザで <http://localhost:8000> を開くと表示されます。サーバーは `Ctrl + C` で停止します。
